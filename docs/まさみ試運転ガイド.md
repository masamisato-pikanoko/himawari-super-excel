# 🌻まさみ試運転ガイド

この試運転は、ExcelをGoogle Driveへ置くとWindows側が原本を保全して整理し、判断が必要な2問だけをGoogle Chatへ出し、回答後に同じ案件の完成Excelを返す入口です。

## 初回だけ

1. `🌻ひまわりシステム🌻` のスプレッドシートを再読み込みします。
2. 上部メニューの `🌻試運転` → `① 試運転の準備` を押します。
3. 「まだ自動運転は停止中です」と表示されれば準備完了です。

Windowsには `HimawariPilotWorker` が5分ごとに動くよう登録されています。開始前は停止スイッチがOFFなので、勝手にExcelを処理しません。

## 1件試す

1. Google Driveの `🌻ひまわりシステム_DEV/INBOX/まさみ試運転` を開きます。
2. その中に案件用フォルダを1つ作ります。例: `社員B_初回テスト`
3. 案件用フォルダには、Excelを1件だけ入れます。領収書画像がある案件では画像も同じフォルダへ入れます。
4. スプレッドシートの `🌻試運転` → `③ 試運転を開始` を押します。
5. 急ぐ場合は `② 今すぐ一周動かす` を押します。通常は10分ごとのGAS確認と5分ごとのWindows確認を待てば進みます。
6. Google Chatへ届く2問に答えます。自由コメントは任意です。
7. 同じ案件が再開され、完成通知のリンクから完成Excelを開けます。

## 困ったとき

`🌻試運転` → `困ったら停止` を押してください。新しい処理だけを止め、原本・途中成果・監査記録は削除しません。

`いまの状態を見る` は、秘密値を表示せずに、開始状態、投入箱、トリガー数、未送信件数を返します。

## 現在の形式対応

- 社員B形式: 画像OCRなしで試せます。
- 社員A形式: 既存のAzure Document Intelligenceを実行時に使います。鍵はGitHubやローカル設定ファイルへ保存しません。Azureログインが切れている場合だけ `OCR_NOT_CONFIGURED` で安全停止します。
- 未知形式: 推測で編集せず `needs_adapter` で停止します。

原本は上書きしません。C/D/Eのブラインド評価ファイルも、この試運転では開きません。
