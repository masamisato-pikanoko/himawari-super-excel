# GitHubの見方

GitHubは、このプログラムの「整理棚」と「変更履歴」です。最初は次の3か所だけ見れば大丈夫です。

1. リポジトリ最初の画面に出る `README.md` で、目的と現在地点を確認します。
2. `super-excel/` でExcel処理本体、`gas/` でGoogle Chat連携を確認します。
3. `Commits` で、Codexがいつ何を変更したか確認します。

## よく使う言葉

- **Repository（リポジトリ）**: プロジェクト専用の保管庫です。
- **Commit（コミット）**: ある時点の変更をまとめた記録です。
- **Branch（ブランチ）**: 本体から分けて安全に試す作業線です。
- **Pull request**: 試した変更を本体へ入れてよいか確認する画面です。
- **Private**: 許可した人以外には見えない状態です。

## この保管庫に入れないもの

社員さんのExcel・画像、APIキー、Webhook、認証コード、サービスアカウント鍵、OCR全文、完成品は入れません。これらはGoogle Driveや秘密情報ストア、案件別作業フォルダに置きます。

## まさみさんがCodexへ頼むとき

「GitHubへ途中保存して」「変更履歴を見せて」「この変更を元へ戻したい」のように自然な言葉で大丈夫です。Codexが保存前に秘密情報と不要ファイルを確認します。
